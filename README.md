# 民生咨询承诺回溯

把公众咨询意见、部门处理和最终政策条款建立可回溯联系。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块只校验资料边界，不预先实现业务流程。

当前资料反映以下领域事实：

- 规划包含住房、医疗和青年发展的量化目标
- 公众咨询意见需要进入政策设计
- 五年蓝图与年度施政安排需要相互衔接
- 五年规划咨询期收到一万七千多份意见
- 提交人希望知道自己的建议最终进入了哪一条政策
- 联署、重复投递和多语文本使工作人员难以给出一致回应
- 提交人授权、意见原文、议题拆分、相似意见归并、部门会签、采纳状态、政策条款和公开答复需要相互连接
- 市民能够用回执查看每个观点的处理去向和理由
- 部门起草者可以看到仍未回应的代表性问题
- 规划发布后能从具体条款回溯支持、反对与未采纳意见，而不是只留下一个总数量

当前资料记录以下处理约束：

- 公众意见归并
- 政策条款关联
- 跨部门会签
- 公开答复回溯
- 撤回或补充只形成新版本
- 个人经历在公开说明中必须脱敏
- 同一联署不能重复计人数
- 跨领域意见允许分别流转
- 未定稿条款和内部争议仅向获授权人员开放

## 本地校验

运行项目自带测试可确认样例资料能够被读取，领域标识、版本、参与方、事实和约束均保持完整。仓库不保存账号、密钥、连接串或真实身份资料。
