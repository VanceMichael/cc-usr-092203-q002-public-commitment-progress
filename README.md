# 民生咨询承诺回溯

把公众咨询意见、部门处理和最终政策条款建立可回溯联系。

## 资料约定

`contracts/domain.schema.json` 描述共享资料的字段结构，`fixtures/domain.json` 提供不含真实个人信息的业务样例。读取模块只校验资料边界，不预先实现业务流程。

当前资料反映以下领域事实：

- 五年规划咨询期收到一万七千多份意见，包含联署、重复投递和多语文本
- 意见经议题拆分、相似归并和部门会签后形成采纳状态，并关联政策条款与公开答复
- 撤回或补充只形成新版本；公开说明中的个人经历必须脱敏；同一联署不重复计人数
- 市民凭回执查看每个观点的处理去向，规划发布后可从具体条款回溯支持、反对与未采纳意见

## 本地校验

运行项目自带测试可确认样例资料能够被读取，领域标识、版本、参与方、事实和约束均保持完整。仓库不保存账号、密钥、连接串或真实身份资料。
